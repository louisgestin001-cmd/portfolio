# AI use statement

This project was developed with substantial assistance from OpenAI's ChatGPT.

AI assistance included:

- converting the proposed scalar law into executable PyTorch code;
- designing preliminary comparison experiments and diagnostics;
- analyzing the piecewise derivatives and period-two involution;
- identifying and testing the odd/even length failure mode;
- drafting tests, benchmark utilities, documentation, and repository structure;
- reviewing the claims to avoid presenting preliminary evidence as established novelty or state-of-the-art performance.

Louis Gestin proposed the candidate law, directed the investigation, requested the comparisons, selected the publication direction, and is responsible for understanding, checking, and presenting the repository's claims.

The reported experimental values were generated in the original local benchmark session on 4 August 2026. The public code is intended to make the core tests reproducible, but the repository should not be treated as independent replication.
